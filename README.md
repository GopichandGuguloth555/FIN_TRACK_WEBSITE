💰 FIN_TRACK_WEBSITE
A Full-Stack Personal Finance Tracking Web Application

📌 Overview
FIN_TRACK_WEBSITE is a full-stack personal finance tracking web application that helps users manage income and expenses, visualize financial data, and gain better control over personal finances by uploading theirs bank statements aor transactions.
The project follows real-world development practices using a modern TypeScript-based MERN architecture with clear separation between frontend and backend.

✨ Features
- User Authentication (Signup & Login using JWT)
- Uploads, view, update, and delete transactions
- Categorized income and expense tracking
- Dashboard with income & expense analytics
- Visual charts for financial insights
- Secure API-based frontend–backend communication
- Responsive and modern UI

⚙️ Installation & Setup

Clone the repository
git clone https://github.com/GopichandGuguloth555/FIN_TRACK_WEBSITE.git
cd FIN_TRACK_WEBSITE

Backend setup
cd BACKEND
npm install

Create .env file inside BACKEND
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

Run backend server
npm run dev

Frontend setup
cd ../frontend
npm install
npm run dev

📡 API Architecture
- RESTful APIs
- JWT-protected routes
- Middleware-based authentication
- Clear separation of concerns (controllers, routes, models)
